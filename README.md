# DickOnTop 网页版（PWA）

这是「运动助手」的网页版替代方案，给 iPhone / Android / 电脑浏览器使用。
iOS 无法直接打包原生 IPA（没有 macOS、Xcode 和苹果签名证书），所以用 PWA 实现同样的功能：
Safari 打开后「添加到主屏幕」，桌面上就会出现一个全屏 App 图标。

## 功能

- 学号 + 统一身份认证密码登录（直接调用学校接口）
- 自动读取本学期规则、今日已上传里程、剩余额度
- 自定义公里数、用时、配速，三者自动换算
- 每天只能上传 1 次（服务器硬性限制），成功后面板锁定到明天；单次上限 6 公里
- 路线规划：开始跑步时向服务器获取本次随机打卡点，在山东理工大学离线地图上按住拖动、用画笔手绘路线（可切换画笔 / 移动地图，画笔模式下双指也能缩放地图），自动校验是否经过全部打卡点，公里数按手绘长度填入
- 竖版离线底图（2304×3584）：手机上整屏铺满、无上下黑边，打卡未开放或直接双击本地 `index.html` 时也能加载底图并手绘路线
- 模拟轨迹：自动生成一条与填写里程等长的环形路线
- 真实轨迹：调用 GPS 记录，可勾选后上传
- 自动识别校区（西校区 / 东校区）
- 上传到 `sports2.sdut.edu.cn`，成功后会刷新今日额度
- 首次打开显示独立免责声明弹窗，强制阅读 5 秒后才能关闭，关闭后才显示使用说明
- PWA：可添加到 iPhone 主屏幕，全屏运行，无开屏更新检测

## 文件说明


## 方式一：本地局域网（最快，先试用）

1. 双击 `serve.bat`（会自动找 Python，并自动避开被占用的端口）；
2. 窗口里会打印实际地址，电脑浏览器打开 `http://localhost:8080`
   （如果 8080 被占用，会自动变成 8081、8082……以窗口显示为准）；
3. iPhone 连同一个 WiFi，打开窗口中显示的 `http://192.168.x.x:端口`；
4. Windows 防火墙弹窗时选择「允许访问」。

注意：局域网是 HTTP，iPhone 会禁用 GPS 定位，但「模拟轨迹」和上传功能不受影响。
「添加到主屏幕」仍然可以用，只是没有离线缓存。

如果双击后提示「没有找到可用的 Python 3」，安装
[Python 3](https://www.python.org/downloads/) 并勾选 `Add python.exe to PATH`，
然后重新打开 serve.bat。不要用 Microsoft Store 的 python 假别名。

## 方式二：Netlify Drop（推荐，免费 HTTPS）

1. 打开 https://app.netlify.com/drop
2. 把整个 `web` 文件夹（或 `DickOnTop网页版.zip`）拖进去；
3. 几秒后得到一个 `https://xxxx.netlify.app` 地址；
4. iPhone Safari 打开该地址 → 分享 → 添加到主屏幕；
5. 想长期保留的话，用邮箱注册一个免费账号即可。

HTTPS 是必须的：只有 HTTPS 页面才能使用 GPS 定位和 PWA 离线缓存。

## 方式三：GitHub Pages

1. 新建一个仓库（Public）；
2. 把 `web` 文件夹里的**内容**上传到仓库根目录（不是把 web 文件夹本身放进去）；
3. 仓库 Settings → Pages → Build and deployment → Source 选 `Deploy from a branch`；
4. Branch 选 `main`，目录选 `/ (root)`，保存；
5. 一分钟后访问 `https://你的用户名.github.io/仓库名/`。

## 方式四：Vercel / Cloudflare Pages

把 `web` 文件夹拖进对应的控制台即可，都是免费 HTTPS。

## 使用步骤

1. 首次打开先阅读免责声明，倒计时 5 秒结束后点「我已阅读并同意」，才会出现使用说明；
2. 输入学号和密码登录；
3. 选择校区，点「开始跑步 · 获取打卡点」：地图上会显示本次随机打卡点；打卡未开放或获取失败时地图仍会打开，可以直接手绘路线；
4. 按住地图拖动即可用画笔手绘路线，双指可随时放大缩小地图；右下角「画笔：开 / 移动地图」可切换画线与拖动；把线画到所有红色打卡点 20 米范围内（可点「自动经过」先连线再手绘微调）；
5. 点「完成」，公里数会按手绘路线长度自动填入并锁定；想改回模拟轨迹就点「清除手绘路线」；
6. 也可以不规划路线，直接选择公里数（3/4/5/6 或手动输入）；
7. 填写用时或配速，另一个会自动算出来；
8. 默认使用模拟轨迹；也可以点「使用当前定位」把轨迹中心换成当前位置；
9. 点「上传本次」，上传前会重新向服务器确认今日次数，通过后计入成绩；
10. 每天只能上传 1 次，成功后按钮立即锁定并显示「今日已上传，明天再来」；
11. 上传时段 05:30–22:30（以服务器时间为准），时段外会被拒绝。

## 当前学期规则（自动读取）

- 男生：最低 3000 米，单次上限 6000 米，配速 3:00–9:00 /公里
- 女生：最低 2500 米，单次上限 6000 米，配速 3:00–9:00 /公里
- 每天 1 次，上传时段 05:30–22:30

这些值会随服务器配置自动更新，页面上的提示是实时读取的。

## 安全与隐私

- 只保存登录返回的用户信息（姓名、学号、userId）在浏览器 `localStorage`；
- **不保存密码**；
- 所有请求直接发往学校服务器，不经过任何第三方中转；
- 点「退出登录 / 清除本机数据」可以清空。

## 已知限制

- 需要有效的学校账号；
- 服务器在 05:30–22:30 之外会拒绝上传（`checkRunAllow` 返回 5001）；
- 每天只能上传 1 次，这是服务器限制；网页版在上传前会再次查询今日记录，查询失败会直接取消上传，避免重复提交；
- 地图是打包在 `map/` 里的高德 z17 静态截图，能离线使用，但不会随道路施工自动更新；
- 打卡点由服务器在点「开始跑步」时随机下发，不同日期/校区可能不同；打卡未开放或获取失败时不会阻塞地图，仍可在无打卡点的情况下手绘路线并按绘制长度上传；
- 如果学校以后修改接口路径、参数或增加签名校验，网页版可能失效；
- 网页版的接口和签名算法来自原 APK 2.0.3，仅用于个人学习，请遵守学校体育规定，风险自负；
- 浏览器会长期缓存标签页图标。本版已给图标文件名加 `v9` 版本号；如果仍显示旧图标，请刷新页面、关闭标签页后重新打开，或清除本站缓存。
